# 02 UI 全面升级方案

> 现状：网页版为单文件原生实现（`public/app.php`），已具备 CSS 变量、响应式 760px 断点、模式切换、批量解析、历史记录等基础能力。

## 1. 当前 UI 审计结果

### 1.1 已具备

- 设计 Token：`--bg`、`--surface`、`--border`、`--text`、`--accent`、`--danger`、`--radius`、`--shadow` 等。
- 语义化结构：`header/main/section/footer`、`aria-label`、`aria-pressed`。
- 响应式：`@media (max-width: 760px)` 覆盖单/批量结果卡片。
- 状态反馈：loading、error、batch progress、成功/失败统计。

### 1.2 问题清单

| 级别 | 问题 | 位置/证据 |
| --- | --- | --- |
| P0 | 批量模式缺少与 `textarea` 绑定的 label；`mode-label` 始终指向被隐藏的单条输入框 | `public/app.php` |
| P0 | 无暗色模式，`<meta name="color-scheme" content="light">` 固定为浅色 | `public/app.php` |
| P0 | 状态区域无 `aria-live`，屏幕阅读器无法感知解析进度/错误 | `public/app.php` |
| P0 | 无统一 Empty 状态（历史为空、批量结果为空时只有隐藏） | `public/app.php` |
| P1 | 多处硬编码颜色：`#0f172a`、`#f6f7f9`、`#fafafa`、`#eef0f3`、`#0b0f19`、`#fffafa` 等 | `public/app.php` CSS |
| P1 | 无 `prefers-reduced-motion`，动画（spinner、transition）不响应系统减动效设置 | `public/app.php` |
| P1 | 无骨架屏；解析中只有单行 loading 文本 | `public/app.php` |
| P1 | 平板断点缺失，仅在 760px 切换 | `public/app.php` |
| P2 | 图标全部为内联 SVG，未统一为图标库 | `public/app.php` |
| P2 | 无国际化（i18n） | 全站 |

## 3. 升级方案（按优先级）

| 优先级 | 升级项 | 方案 |
| --- | --- | --- |
| P0 | 暗色模式 | `color-scheme: light dark` + `prefers-color-scheme`，深色 Token 覆盖 `--bg/--surface/--text/--border` 等 |
| P0 | 无障碍修复 | 批量 `textarea` 增加独立 label；loading/error/progress 加 `aria-live="polite"`；按钮补 `aria-label` |
| P0 | 状态补齐 | Empty、Loading、Error 三类状态统一组件；解析中显示骨架卡片而非纯文本 |
| P1 | 微交互 | hover/active/焦点环统一；遵循 `prefers-reduced-motion` |
| P1 | 响应式补全 | 增加 1024px/760px/480px 三档；结果卡片、历史卡片、批量操作区逐档验证 |
| P2 | 图标统一 | 继续使用内联 SVG（无构建依赖）或引入 lucide 图标集，统一尺寸 16/18px |
| P2 | 国际化 | 抽取中文文案为 `data-i18n` 字典，支持 `zh-CN/en` |

## 4. 验收标准

- Lighthouse Accessibility ≥ 90（WCAG 2.1 AA）。
- 暗色模式下对比度满足 AA（正文至少 4.5:1）。
- 桌面/平板/手机三档均无文字溢出、元素重叠。
- 键盘可完成全部操作：输入、粘贴、解析、切换模式、历史操作。
