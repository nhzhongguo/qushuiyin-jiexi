# 06 综合升级路线图

> 基于 01-05 报告汇总，分阶段执行；所有变更均在确认后实施。

## 阶段总览

| 阶段 | 目标 | 主要内容 | 预估工时 | 风险 |
| --- | --- | --- | ---: | --- |
| Phase 0 | 环境与清理 | 确认并执行日志/限流清理；锁定基线 | 0.5 天 | 低 |
| Phase 1 | UI 升级 | 暗色模式、a11y、状态组件、响应式 | 2-3 天 | 低 |
| Phase 2 | 性能升级 | 解析缓存、批量并发、签名优化 | 2-3 天 | 中（缓存过期策略） |
| Phase 3 | P0 功能 | 多平台、API 服务化、直播流解析 | 5-7 天 | 高（平台接口变动） |
| Phase 4 | P1 功能 | 音乐下载、主页批量、去水印增强 | 5-7 天 | 中（合规边界） |
| Phase 5 | P2 功能 | PWA、插件、SDK、Bot、HLS | 7-10 天 | 中 |

## Phase 0：确认与清理

- [x] 清空 `storage/logs/app.log`
- [x] 清理 `storage/rate_limit/*.json`
- [x] 记录清理前后体积

## Phase 1：UI 升级

1. Token 化：补齐颜色、间距、圆角、阴影、动效变量。
2. 暗色模式：`prefers-color-scheme` + 手动切换。
3. 无障碍：label、`aria-live`、焦点、reduced-motion。
4. 状态组件：Loading / Empty / Error / Skeleton。
5. 响应式：1024 / 760 / 480 三档验证。

## Phase 2：性能升级

1. 解析结果缓存（TTL 24h）。
2. 批量解析前端限流并发。
3. a_bogus 签名进程复用。
4. HTTP 缓存头与媒体代理调优。

## Phase 3：P0 功能

1. 扩展解析器：快手、小红书、视频号、B 站、西瓜视频。
2. API 服务化：版本化路由、Token、OpenAPI、Docker。
3. 直播流解析接口。

## Phase 4：P1 功能

1. 音乐/音频下载。
2. 作者主页批量解析（确认合规边界）。
3. 图集与合集去水印。
4. 可选 Electron 桌面壳。
5. AI 去字幕/水印评估。

## Phase 5：P2 功能

1. PWA（安装、离线缓存、分享）。
2. 浏览器扩展（嗅探页面视频）。
3. Composer SDK 封装。
4. M3U8/HLS 支持。
5. Telegram Bot。

## 风险与应对

| 风险 | 等级 | 应对 |
| --- | --- | --- |
| 短视频平台接口/风控频繁变更 | 高 | 解析器可配置、多路径回退、定期冒烟测试 |
| 批量/账号类功能合规风险 | 中 | 仅提供用户主动提交链接的批量，不提供撞库/遍历 |
| 外部开源代码许可证冲突 | 中 | 引入时保留 LICENSE，优先同 AGPL 项目参考 |
| AI 去水印资源成本 | 中 | 作为可选二期功能，默认关闭 |

## 验收条件

- `php bin/lint.php` 全部通过。
- 每个新增平台有真实链接冒烟测试。
- Lighthouse：Performance ≥ 90、Accessibility ≥ 90、Best Practices ≥ 90。
- 旧 API 与网页功能无回归。
