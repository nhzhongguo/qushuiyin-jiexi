## 1. 本次修复的问题

### 1.1 UTF-8 BOM 导致 lint 失败（阻塞项）
- 现象：`php bin/lint.php` 对 3 个文件报错
  - `app/Parsers/DouyinParser.php`：`Namespace declaration statement has to be the very first statement`
  - `app/Services/MediaProxy.php`、`public/index.php`：`strict_types declaration must be the very first statement`
- 根因：上述文件（含 `public/app.php`）带 UTF-8 BOM（`EF BB BF`），PHP 8.1 lint 将其视为声明前输出。
- 修复：移除 4 个文件的 BOM；全项目扫描确认无残留。
- 结果：`php bin/lint.php` 28/28 通过，exit 0。

### 1.2 PHP 内置服务器无法路由 `/api/v1/*`
- 现象：`php -S` 下 `/api/v1/health`、`/platforms`、`/parse` 全部 404（.htaccess 仅 Apache 生效）。
- 修复：新增 `public/router.php`（与 `.htaccess` 同规则：静态文件直出、`/api/v1/*` → `api/v1.php`、其余 → `index.php`），并更新 `composer.json` 的 `serve` / `serve:full` 脚本。
- 结果：`GET /api/v1/health`、`/api/v1/platforms`、`/api/v1/parse` 全部可用。

### 1.3 本机 PHP 未加载扩展
- 现象：`Call to undefined function App\Services\curl_init()`。
- 根因：WinGet 安装的 PHP 8.1.34 无活动 `php.ini`，`ext-curl` 未启用。
- 修复：在 PHP 安装目录生成 `php.ini`（`extension_dir=ext`，启用 curl/openssl/mbstring/fileinfo/gd/sockets/sqlite3/pdo_sqlite/intl，`date.timezone=Asia/Shanghai`）。
- 结果：curl 可用，MediaProxy 流式转发恢复。

### 1.4 a_bogus 常驻签名服务启动即退出
- 现象：`node scripts/a_bogus_server.js` 打印 Usage 后退出，端口 9876 拒绝连接。
- 根因：服务用 `eval()` 加载 `a_bogus.js`，而该文件 CLI 分支判断 `require.main === module` 在 eval 上下文中恒为真，导致执行 CLI 退出分支。
- 修复：改为 `const { get_ab } = require("./a_bogus.js")`。
- 结果：签名服务 200 返回 188 位签名，DouyinParser 走常驻服务（2ms）成功。

### 1.5 新增解析器逻辑缺陷
- `KuaishouParser`：`/v/xxx` 回退分支是死代码（`$photoId` 在到达前必然已赋值）；重构为多模式提取，`/photo/xxx`、`/short-video/xxx`、`/v/xxx` 均可识别。
- `XiguaParser`：`/(\d+)/` 会命中 URL 中任意首个数字；改为优先匹配 `/video/xxx`、`/item/xxx`，兜底匹配 10-25 位纯数字。
