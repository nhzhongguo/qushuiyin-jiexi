## 2. P0 功能实施计划

### 2.1 多平台解析/下载（P0）

参考项目：`wujunwei928/parse-video`、`wujunwei928/parse-video-py`、`qq6865373/qsyapi`、`ucmao/media-parser`、`liuchuancong/parse_video`。

- 新增解析器：快手、小红书、视频号、B 站、西瓜视频。
- 统一 `BaseParser` 契约与结果字段，保持现有 API 不变。
- 每个解析器配 1 条真实链接冒烟测试。
- 保留外部代码 LICENSE 声明（AGPL-3.0 等项目需注明来源）。

### 2.2 Web API / 解析服务（P0）

参考项目：`ucmao/media-parser`、`wouldmissyou/MoreAPI`、`milancodess/universalDownloader`。

- 增加 `GET /api/v1/parse`、`GET /api/v1/platforms`。
- 增加 API Key 鉴权（可选开启）与 OpenAPI 描述文件。
- 增加 `Dockerfile` + `docker-compose.yml`（Nginx + PHP-FPM）。
- 保持旧接口向后兼容。

### 2.3 直播流解析（P0）

参考项目：`ihmily/streamget`、`ihmily/DouyinLiveRecorder`、`Michele0303/tiktok-live-recorder`。

- 先实现“直播间地址解析为可播放流”接口，不直接做自动录制。
- 接入 `MediaProxy` 播放，减少落地存储风险。

## 3. P1 功能实施计划

| 功能 | 实施内容 | 参考项目 |
| --- | --- | --- |
| 音频/音乐下载 | 抖音解析返回音乐直链，前端增加“下载音乐”按钮 | `TikTokDownloader`、`TobyG74/tiktok-api-dl` |
| 批量/主页下载 | 增加作者主页 ID 批量拉取（需用户确认合规边界） | `jiji262/douyin-downloader` |
| 去水印增强 | 支持图集（多图）与合集列表 | `jiuhunwl/short_videos`、`liuchuancong/parse_video` |
| 桌面 GUI | 可选 Electron 壳，复用现有 Web UI | `FileCentipede`、`youwee` |
| AI 去字幕/水印 | 二期引入本地模型，需评估 GPU/CPU 成本 | `YaoFANGUK/video-subtitle-remover` |

## 4. 实施约束

1. 每一步先输出分析结果，确认后再执行变更。
2. 集成外部代码保留原始 LICENSE 声明。
3. 每个功能完成后运行 `php bin/lint.php` + 对应平台冒烟测试。
4. 平台接口变更时，优先更新 `scripts/a_bogus.js` 与对应解析器，不改动对外 API 契约。
